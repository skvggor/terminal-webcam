Your webcam,
as ASCII art.

A tiny tool that grabs your webcam and paints it into your terminal. Monochrome or full color, centered, square, no stretching.

uv run capture.py

Live demo

Processed entirely in your browser via getUserMedia. No upload, no storage.

Two modes

Run it locally

Linux, with uv:

# clone & install
git clone https://github.com/skvggor/terminal-webcam
cd terminal-webcam
uv sync

# monochrome / color
uv run capture.py
uv run color.py

# list cameras and the detected aspect ratio
uv run capture.py --list

# pick a camera, tune aspect & fps
uv run capture.py --device 2 --aspect 2.2 --fps 15

Press ESC or Ctrl+C to quit.

What's inside

  • Square crop Centered, never stretched.
  • Camera picker Lists real capture devices by name and resolution.
  • FPS cap Throttled render loop, low CPU.
  • ESC to quit Non-blocking input, clean curses teardown.
